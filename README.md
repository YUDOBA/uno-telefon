# Uno Telefon

Farkli telefonlardan oda kodu ile katilinancok oyunculu Uno.

## Nasil calisir

1. Bir kisi Oyun Kur der, oyuncu sayisi ve ismini girer.
2. 4 haneli oda kodu olusur.
3. Digerleri Katil deyip kodu ve isimlerini girer.
4. Sayi dolunca kurucu Baslat basar.
5. Standart Uno kurallariyla oynanir.
